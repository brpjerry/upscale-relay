This release adds desktop library and playback features while retaining the
Local and Server tree browsers.

- Nearby servers appear beside manual address entry. Select an address, then
  choose Connect.
- Playback history automatically resumes eligible positions and shows watched
  status in both browsers. Progress saves every five seconds; resume excludes
  the first ten and final 90 seconds, and the final 90 seconds count as watched.
  History retains 50 entries by default, adjustable from 1 to 1,000. Server
  history is separate for each configured host and port.
- Autoplay is enabled by default and advances to the next unwatched sibling in
  alphabetical order after natural completion. It does not recurse or wrap.
- Name/Newest sorting is shared by both browsers, with directories first.
  Browser tabs, expanded directories, selection, and scroll context are restored.
- Model, quality, framing, and resize-filter changes preserve playback position,
  pause intent, audio/subtitle choices, and delays. Track choices are matched by
  metadata when native IDs change.
- The settings panel exposes subtitle defaults, ordered subtitle languages,
  video synchronization, interpolation, and its scaler. These settings modify
  the shared user `mpv.conf` and also affect standalone mpv. Existing comments,
  profiles, and unrelated options are preserved; external edits apply to the
  next opened session. Current-video track selections stay session-only.
- Scrubbing previews a timestamp and signed delta, commits one seek on release,
  and supports cancellation. New buttons seek backward or forward ten seconds.
- Diagnostic display and file logging can be enabled independently; both default
  off. Client logs use timestamped files in Documents, redact URLs and tokens,
  and retain ten files with bounded queues and size-based rollover.
- FFV1 relay playback works with libmpv older than 0.38 by selecting its
  libavformat demuxer for the newer `V_FFV1` container tag. Player messages also
  gain black shadows for readability over bright video.

The Arch Linux client package and Windows server ZIPs use version 0.21.0.
No protocol version change is required. See the
[desktop feature guide](../docs/DESKTOP_FEATURES.md) for behavior and persistence
details, and the [parity report](../docs/DESKTOP_ANDROID_PARITY.md) for remaining
desktop gaps.
