This patch smooths the desktop client's fullscreen transitions, makes its
fluid-interface mode a hybrid, and tidies the Windows server GUI.

- The interface stays fluid during playback without giving up mpv's frame
  timing in fullscreen. The Video timing switch, now "Fluid interface during
  playback", paces video by the display while the window is not fullscreen
  and through fullscreen transitions, then hands frame timing back to mpv
  once the window has settled in fullscreen, where display pacing costs about
  3 W on a laptop. mpv switches either way in about 0.2 s without dropping a
  frame. The Video synchronization list offers audio and the two display
  modes worth choosing; any other value in mpv.conf is still shown and kept.
- Entering and leaving fullscreen is smoother. The video keeps its final size
  through the transition while the chrome slides over it and the window grows
  or shrinks around it, instead of being re-laid-out at every step of the
  slide. Measured on Hyprland with 2880x1620 HEVC from the server, the
  longest stall in a transition fell from about 130 ms to about 50 ms and
  dropped frames per fullscreen round trip from 12 to 5.
- The Windows server GUI wears the desktop client's theme and widgets, and the
  `server-gui` extra needs only `PySide6-Essentials`. Cancelling the NVIDIA
  runtime setup closes the dialog at once and ends the installer's whole
  process tree; Quit is always available and no longer waits out aiohttp's
  shutdown timeout on idle client connections; when an encoder fails to open,
  the server records what libav said about it (for example the NVENC session
  limit).

The Arch Linux client package and Windows server ZIPs use version 0.22.1.
No protocol version change is required.
