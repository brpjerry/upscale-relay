This release gives the desktop client a new look and collects the two changes
merged since 0.21.1.

- The desktop client is restyled to match MV Player: a flat dark or light
  palette with one accent colour, round icon buttons, a thin seek bar with
  chapter marks and a time bubble, toggle switches, and Material icon
  outlines. The theme follows the system by default; Playback settings has a
  Follow system / Dark / Light choice.
- The window is rearranged around that look. The file browser is a sidebar
  with the connection state in its footer, the top bar shows the playing file
  and the current status message, and one control bar carries now-playing,
  transport and seek, volume and fullscreen.
- Audio, subtitle and chapter selectors, with their delays, moved into a card
  opened from the subtitles button; it is available in fullscreen too.
- Playback settings is a sheet over the right edge instead of a dock, so
  opening it no longer widens the window past a tiling compositor's tile.
  "Connect automatically on launch" moved into it. Escape closes the track
  card, then the sheet, then fullscreen.
- The skip buttons step by a configurable amount (default 1:25), set in
  Playback settings.
- The relay server refuses to start a second instance on the same machine.

The Arch Linux client package now depends on `qt6-svg`. The Arch Linux client
package and Windows server ZIPs use version 0.22.0. No protocol version change
is required.
