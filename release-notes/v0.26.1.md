This patch fixes colour banding in the desktop client on Linux with NVIDIA.

- The desktop client asks for at least 8 bits per colour channel for its
  window. It asked for no depth, and with Qt 6.12 on Wayland, NVIDIA's EGL
  gave it a 16-bit (RGB565) surface: every frame mpv rendered was cut to 5,
  6 and 5 bits for red, green and blue when Qt composited the window. Smooth
  gradients, dark scenes especially, showed coarse bands, each channel
  stepping at a different place, so the bands changed colour. Plain mpv,
  which draws its own window, did not show them.

The Arch Linux packages (`upscale-relay-common`, `-client` and `-server`)
and the Windows server ZIPs use version 0.26.1. No protocol version change
is required.
