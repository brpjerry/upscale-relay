This release adds an Arch Linux pacman package for the desktop and headless
clients alongside the existing Windows server downloads.

- `upscale-relay-client-0.20.0-1-any.pkg.tar.zst` installs `relay-desktop`,
  `relay-client`, and an application-menu entry. Pacman installs the system
  dependencies, including libmpv and Qt's native Wayland plugin.
- The client package excludes server and offline inference code, models, and
  NVIDIA runtimes. No virtualenv or pip installation is needed.
- Release publishing waits for both platform builds. CI installs the pacman
  package and checks command startup, GUI/libmpv initialization, and the
  Wayland plugin outside the source checkout.

On Arch Linux, download the package and `SHA256SUMS` into the same directory,
then run:

```bash
sha256sum -c SHA256SUMS
sudo pacman -U ./upscale-relay-client-0.20.0-1-any.pkg.tar.zst
relay-desktop
```

The package uses Arch's Python minor version at build time and requires a
rebuild when that minor version changes. See `docs/CLIENT_LINUX.md` for source
build instructions.

The Windows downloads contain the tray app (`-gui`) and headless console server
(plain ZIP). Extract the entire chosen ZIP before running its executable.
The NVIDIA runtime is installed on first launch and reused thereafter.
