This release brings the September reliability audit fixes to the server,
desktop client, and offline tools. Pair it with Upscale Relay Android v0.19.0
for the corresponding Android playback and lifecycle fixes.

- Session shutdown now closes owned sockets and workers, rolls back failed
  startup, and blocks replacement sessions when native cleanup is unconfirmed.
  Tray startup, Apply, and restart operations are serialized.
- Rapid and paused seeks preserve the latest request, track choices, and pause
  intent. Desktop playback can seek again after the server has finished sending
  the current stream.
- Text subtitles that overlap a seek target are restored through a bounded,
  temporary session index. Clients receive progress while unseen subtitle
  coverage is indexed. Bitmap and stateful subtitles retain external playback.
- Video-only and subtitle-only sources avoid unnecessary audio attachment.
  Local fallback supports immediate pause and seek; desktop playback settings,
  transport controls, and fullscreen contrast are improved.
- Media framing, queues, font-cache ownership, and worker handoffs have tighter
  resource bounds. Offline conversion rejects output paths that alias the input,
  and benchmarks use the actual output dimensions and clean up temporary files.

The Windows downloads contain the tray app (`-gui`) and headless console server
(plain ZIP). Extract the entire chosen ZIP before running its executable.
The NVIDIA runtime is installed on first launch and reused thereafter.

The audit includes automated regressions and recorded Windows GPU/LAN and
Wayland desktop playback checks. The previously documented intermittent native
NVIDIA crash remains unresolved; these changes do not claim to fix it.
