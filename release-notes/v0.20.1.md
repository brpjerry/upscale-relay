This patch fixes three desktop playback issues:

- Resuming after a long pause no longer drains the remaining cache and returns
  to “Choose a video.” Relay streams now allow the localhost TCP reader to wait
  through intentional pauses without mpv's network timeout turning them into
  end-of-file. Normal end-of-file, stop, seek, and transport closure still work.
- Fullscreen hides the cursor after inactivity and restores it on mouse motion
  or exit. The pointer remains usable over the playback controls and while
  dragging the seek slider.
- Frames intentionally not displayed on another Wayland workspace are
  acknowledged through libmpv's render API instead of accumulating as dropped
  frames. Playback continues while the window is unexposed, and ordinary
  visible playback still reports actual renderer drops.

The Arch Linux client package and Windows server ZIPs use version 0.20.1.
The server protocol and inference behavior are unchanged.
