This patch fixes slow far seeks in server-file sessions with subtitles, and
ships the desktop features prepared for 0.21.0, which was never published.

- A forward seek into an unplayed part of a server file with indexable
  ASS/SSA, SubRip, WebVTT, or plain-text subtitles now scans at most 10 seconds
  of source before the target to recover overlapping subtitle events. It
  previously demuxed the whole unplayed prefix, so a far seek in a long file
  read nearly the entire file before the first frame. Repeated and backward
  seeks still reuse the per-session index.
- Everything in the [v0.21.0 notes](v0.21.0.md) is included: nearby server
  discovery, playback history and resume, autoplay, shared browser sorting,
  position-preserving quality changes, mpv settings, seek preview, diagnostics
  logging, and FFV1 playback on older libmpv.

The Arch Linux client package and Windows server ZIPs use version 0.21.1.
No protocol version change is required.
